# Словарь WinVosk: по одному слову или словосочетанию в строке,
# без знаков препинания. Список работает в двух режимах:
#
# 1. Проверка: какие из этих слов модель вообще способна услышать.
#    Кнопка "Проверить свои слова" во вкладке Настройки, или из консоли:
#
#     .\.venv\Scripts\python.exe .\src\run.py --vocab-check
#
# 2. Исправление при диктовке: если модель слышит слово как что-то похожее,
#    готовая фраза приводится к вашему варианту. Например "дропбок" ->
#    "дропбокс". Работает только на законченных фразах, отключается
#    галочкой "Исправлять свои слова" во вкладке Настройки.
#
# Правила: слова короче четырёх букв не трогаются, порог похожести 0.85,
# каждая замена пишется в logs\app.log. Однословные записи участвуют в
# исправлении, многословные — только в проверке.
#
# Слова помечены MISSING, если модель их не знает. Добавить их можно только
# пересборкой языковой модели через Kaldi на Linux, см. README.md, раздел
# "Custom vocabulary". Если диктуете не по-русски, список должен быть на том
# же языке, что и модель.
#
# Подробности: README.md (English) и README.ru.md (Русский), раздел
# "Custom vocabulary".
