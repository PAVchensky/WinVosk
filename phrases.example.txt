# Словарь WinVosk: по одному слову или словосочетанию в строке,
# без знаков препинания. Список работает в двух режимах:
#
# 1. Проверка: какие из этих слов модель вообще способна услышать.
#
#     .\.venv\Scripts\python.exe .\src\run.py --vocab-check
#
# 2. Исправление при диктовке: если модель слышит слово как что-то похожее
#    или расщепила его на два ("друг бокс"), готовая фраза приводится к вашему
#    варианту. Например "дропбок" -> "дропбокс". Работает только на законченных
#    фразах, отключается галочкой "Исправлять свои слова" во вкладке Настройки.
#
# Правила: слова короче четырёх букв не трогаются, порог похожести 0.75,
# каждая замена пишется в logs\app.log. Однословные записи участвуют в
# исправлении, многословные — только в проверке.
#
# Слова, помеченные MISSING, модель не знает. Их можно добавить только
# пересборкой языковой модели через Kaldi на Linux, см. docs\HOWTO.md.
#
# Это пример: скопируйте файл как phrases.txt и замените слова на свои.
# Если файла нет, приложение работает, просто список слов пуст.
